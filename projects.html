Projects

A selection of research implementations, production AI systems, and interactive tools spanning computer vision, edge deep learning, conversational agents, and MLOps.

FactoryEye – A Real-Time AI Defect Detection System

[GitHub Repo]
YOLO Computer Vision Manufacturing AI Weights & Biases Docker

FactoryEye is a production-grade automated visual inspection system engineered for high-throughput manufacturing lines. It processes real-time image feeds or video frames of steel surfaces using a fine-tuned YOLO model to pinpoint surface irregularities and micro-defects with high precision. The system outputs bounding coordinates, defect classification confidence, instant alert notifications, and continuous experiment tracking via MLOps pipelines.

Leaf Scan – Tomato Disease Identification

[Live Demo] [GitHub Repo] [Technical Report]
Transfer Learning InceptionV3 TensorFlow.js Agricultural AI Edge Inference

A deep learning application leveraging transfer learning to diagnose multiple categories of tomato foliar diseases. The fine-tuned InceptionV3 model achieves over 97% validation accuracy. By converting the model to TensorFlow.js, inference executes directly in the user's browser without requiring server processing, allowing rapid diagnostics in bandwidth-constrained rural farming environments.

Finger Rumble – In-Browser Gesture Recognition

[Live Demo] [GitHub Repo] [Technical Report]
TensorFlow.js Transfer Learning KNN Classifier Webcam AI

An interactive web application applying transfer learning via TensorFlow.js to recognize hand gestures in real time directly through the user's webcam. Users collect gesture samples (Rock, Paper, Scissors, Spock, Lizard) on the fly, fine-tune the classifier live in memory, and immediately test predictions for hands-free interactive gameplay.

MathKid – Handwritten Digits Recognition

[Live Demo] [GitHub Repo] [Technical Report]
CNN MNIST Educational AI Deep Learning

An educational web application that helps children develop and validate early mathematics skills. The system incorporates a Convolutional Neural Network trained on the MNIST handwritten digits dataset. Children draw digits on an interactive HTML5 canvas, and the model recognizes and verifies the written input in real time.
